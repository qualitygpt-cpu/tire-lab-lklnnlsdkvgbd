# TireLab

TireLab — это публичный статический проект для поэтапной разработки расчетной модели деформации автомобильной шины.

## Текущий этап

Первая стадия: только инициализация структуры проекта, базовый интерфейс и документация. Полноценное расчетное ядро пока не реализовано.

## Запуск

1. Локально: откройте `index.html` в браузере.
2. Через GitHub Pages: включите публикацию из ветки `main`, папка `/ (root)`.

## Legacy-прототип

Старый однофайловый прототип уже добавлен в `legacy/tire_reduced_fem_model_original.html` и хранится без изменений как baseline-эталон для поэтапного рефакторинга и регрессионной проверки.

## How to test the app manually

1. Откройте `app/index.html`.
2. По очереди выберите сценарии в поле **«Расчетный сценарий»**.
3. Для каждого сценария проверяйте блок **«Что проверить»** и ключевые метрики (`Fx`, `Fy`, `длина пятна`, `площадь пятна`, `p max`, `tau / mu p`).
4. Сверяйте результаты с чек-листом из `tests/reference-cases.md`.
5. После каждого изменения UI/ядра повторите весь список ручных регрессионных сценариев.

## Development rules

- держать физическую модель отдельно от рендеринга;
- документировать формулы до их реализации в коде;
- добавлять manual test cases для каждого изменения модели;
- по возможности не менять формулы и UI в одном PR.
