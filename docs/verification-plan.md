# Verification plan

Верификация модели будет выполняться по нескольким направлениям:

- regression against legacy prototype;
- dimensional checks;
- sanity checks;
- qualitative behavior checks;
- manual reference cases.

На раннем этапе приоритет — повторяемость поведения и контроль размерностей до добавления сложной физики.

## Manual regression testing after each PR

Ниже — обязательный smoke-набор сценариев, который выполняется вручную после каждого PR в модульное приложение.

| Preset | Expected behavior | Main metrics | Visual check |
|---|---|---|---|
| Базовый легковой автомобиль | Стабильный baseline без артефактов | `F_n расчет`, `длина пятна`, `p max`, `Fx/Fy` | Пятно контакта непрерывное, графики заполнены |
| Низкое давление | Рост площади/длины пятна и деформации | `длина пятна`, `площадь пятна`, `мин. w` | Контактная зона шире базовой |
| Высокое давление | Снижение площади/длины пятна и деформации | `длина пятна`, `площадь пятна`, `мин. w` | Контактная зона уже базовой |
| Большая нагрузка | Рост нормальной силы и прогиба | `F_n расчет`, `мин. w`, `площадь пятна` | Больше сплющивание внизу шины |
| Продольный уклон | Перераспределение продольных сил | `Fx`, `Mz`, `tau_x` | Изменение формы графика `tau_x` |
| Боковой уклон | Рост бокового отклика | `Fy`, `макс. |y|`, `tau_y` | Видна боковая асимметрия |
| Поворот с углом увода | Выраженный cornering-эффект | `Fy`, `tau_y`, `tau / mu p` | Сдвиговые графики показывают боковой вклад |
| Скользкое покрытие | Раннее насыщение по трению | `tau / mu p`, `Fx`, `Fy` | Ограничение по tau заметно визуально |
| Торможение | Продольный тормозной режим | `Fx`, `tau_x` | `tau_x` доминирует, знак как в модели |
| Разгон | Продольный тяговый режим | `Fx`, `tau_x` | Знак `Fx` противоположен торможению |
