# Model assumptions (planned)

Планируемая редуцированная модель:

- шина как деформируемое кольцо;
- контакт с дорогой через penalty method;
- оценка пятна контакта;
- brush model для продольных и поперечных касательных деформаций;
- учет продольного уклона и поперечного банкового наклона дороги.

## Ограничения

- это не полный 3D FEM;
- слои корда пока не моделируются;
- гиперупругая модель резины пока не вводится;
- тепловая модель отсутствует;
- валидированная динамика качения пока отсутствует.
