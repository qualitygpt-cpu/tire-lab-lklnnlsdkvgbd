Reduced FEM модель деформации бескамерной шины на уклоне

Расчетная демонстрация: покрышка задается кольцом из узлов. Считаются радиальная деформация w, окружное смещение u, боковое смещение y, окружная деформация epsilon, контактное давление, brush-сдвиг протектора и пятно контакта.

Это не промышленная 3D FEM-модель. Для точного расчета реальной шины нужны: слои корда, брекер, гиперупругая резина, контакт с диском, рисунок протектора, температура, качение и 3D контакт. Здесь реализован reduced FEM: elastic ring + penalty contact + brush model.

Параметры

Прогресс расчета: 0%
Итерация: 0 / 0
Остаток: -

Модель

r_i = C + (R0 + w_i)e_r + u_i e_t + y_i e_y epsilon_i = du/ds + w_i/R0 + 0.5(dw/ds - u_i/R0)^2 chi_i = d2w/ds2 - (1/R0)du/ds p_i = kc max(0, -g_i) tau = kb q, |tau| <= mu p_i

Цвет контура показывает окружное сжатие и растяжение. Стрелки в контакте показывают сдвиг протектора и боковой увод.
